# Pet-A-Cat

Pet-A-Cat (or get a scratch…) is a fast-paced, whack-a-mole style game where your goal is simple - pet as many cats as you can! But be careful - some cats aren’t meant to be touched.

## Usage

### Install

Clone and install dependencies:

```bash
git clone git@github.com:MartinTale/js13kgames-2025.git
cd js13kgames-2025
npm i
```

### Dev server

Start the dev server with hot reload:

```bash
npm run dev
```

Open your web browser to <http://localhost:5173/>

### Production build

Create a final production build:

```bash
npm run build
```
